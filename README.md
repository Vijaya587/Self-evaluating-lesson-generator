## Self-Evaluating Lesson Content Generator
This project generates educational lessons and evaluates them using six quality checks. 

## Technologies
- Python
- Streamlit
- LangGraph

## Features
- Lesson generation
- Six quality checks
- Rejection log
- Final lesson
- Quiz with answers

## Installation

pip install streamlit langgraph openai python-dotenv

## Run the Application

streamlit run app_free.py
